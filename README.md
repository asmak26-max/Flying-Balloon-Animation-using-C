# Flying-Balloon-Animation-using-C

🎈 Balloon Animation

A small C graphics mini-project demonstrating basic computer graphics and animation concepts.

📌 Overview

The project creates a simple animated visual using a classic C graphics environment.

It was developed as a learning project to practice graphics programming, screen coordinates, movement, and animation.

🛠️ Technology

- C
- "graphics.h"
- BGI graphics environment

✨ Highlights

- Basic graphical animation
- Multiple moving graphical objects
- Randomized visual elements
- Keyboard-controlled termination

🎯 Purpose

This project demonstrates how fundamental C programming concepts can be combined with graphics to create a simple animated application.

▶️ Execution

The project requires a compatible legacy C graphics environment supporting "graphics.h"/BGI.
